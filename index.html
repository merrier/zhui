把中国风做成一套可复用的 UI 语言。

它不是“加一个红色按钮”那么简单。Zhui 把宣纸、墨色、朱砂与现代排版放进同一套组件系统里：既能开箱即用，也能继续雕琢成你自己的风格。

一页说清楚：为什么是 Zhui

— 已支持组件
React 组件库（TypeScript）
适合做品牌组件库、后台系统、内容站点与活动页。你可以从 Storybook 开始，也可以直接复制这套排版与色彩节奏，构建你的设计系统。

特色

用一致的色彩、边界、阴影与排版，把“气质”变成可维护的工程资产。

宣纸质感的层次

柔和底色、细密纹理与微妙暗影，让界面像纸张一样“有厚度”，不靠噱头也能耐看。

朱砂强调与克制

把红色当作印章，不当作背景。关键动作更醒目，其他信息更安静。

组件是语法，不是素材

按钮、表单、反馈、数据展示与导航在同一套规则里，组合起来不会“撞气质”。

全部组件

搜索与筛选都在前端完成；点击卡片可展开示例与代码片段。

快速上手

把安装与最小用法直接贴进你的项目，然后再按需引入组件样式与主题。

安装

npm install zhui
复制命令，一行搞定

使用

import React from "react";
import ReactDOM from "react-dom";
import { Button } from "zhui";

ReactDOM.render(
  <Button>朱砂按钮</Button>,
  document.getElementById("root")
);
